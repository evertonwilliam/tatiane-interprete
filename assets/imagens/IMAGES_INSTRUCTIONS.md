# 📸 Instruções para Adicionar Imagens

## Imagens Necessárias

Baixe ou crie imagens para os placeholders:

### 1. Hero Section
- **tatiane-leao-hero.jpg**: Foto profissional da Tatiane (280x280px mínimo)
  - Recomendado: Foto de perfil profissional, bem iluminada
  - Formato: JPG ou PNG
  - Proporção: Quadrada (1:1)

### 2. Portfólio (6 imagens)
- **portfolio-evento.jpg**: Interpretação em evento
- **portfolio-educacao.jpg**: Aula de Libras
- **portfolio-saude.jpg**: Ambiente de saúde
- **portfolio-treinamento.jpg**: Treinamento corporativo
- **portfolio-inclusao.jpg**: Ações de inclusão
- **portfolio-consultoria.jpg**: Consultoria em acessibilidade

Todas as imagens de portfólio:
- Tamanho: 300x250px mínimo
- Formato: JPG ou PNG
- Proporção: Paisagem (4:3 ou similar)

## Como Adicionar Imagens

1. Salve as imagens na pasta `imagens/`
2. Use os nomes sugeridos acima
3. Certifique-se de ter permissão para usar as imagens

## Dicas de Imagens

✅ Qualidade: Mínimo 800x600px
✅ Otimização: Use ferramentas como TinyPNG para reduzir tamanho
✅ Contraste: Escolha imagens com bom contraste
✅ Relevância: Imagens que realmente representem o trabalho

---

**Nota**: Sem imagens, os placeholders aparecerão como imagens em branco. Recomenda-se adicionar imagens para melhor apresentação.
